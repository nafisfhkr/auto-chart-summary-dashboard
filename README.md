# Auto Chart Summary Generation

Prototype sistem untuk menghasilkan ringkasan otomatis dari data chart menggunakan deterministic insight engine dan LLM.

## Prototype Stack

- Python
- PostgreSQL / Supabase
- 9Router
- Apache Airflow
- FastAPI

## Data Notice

This repository uses synthetic/dummy data for development and demonstration purposes.

No private or internal organizational data is included.

## Status

Prototype in development.
